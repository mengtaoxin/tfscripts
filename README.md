# tfscripts

tfscripts is a small collection of command-line helpers for everyday work on a Mac. It exists so the little chores you repeat often—keeping the machine awake through a long job, retrying a flaky command, juggling several git checkouts, opening a folder in your editor—live in one shared toolkit instead of as scattered one-off aliases.

Reach for it when you want those kinds of utilities as ready-made commands rather than rewriting them each time.
